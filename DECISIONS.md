# Decision Log

| ID | Date | Decision | Why | Alternatives considered |
|---|---|---|---|---|
| D-001 | 2026-10-20 | Host on public GitHub with real, unaltered commit history, plus a separate portfolio page for readers | Commit history is evidence of process. Dates and history are never altered. | Portfolio page or PDF only (less checkable) |
| D-002 | 2026-10-20 | Universe: UCITS ETFs sold in the UK/EU | Most comparable; key documents follow a standard format | US-listed ETFs (different documents and fee conventions) |
| D-003 | 2026-10-20 | (Closed by D-008) Index scope: undecided. Survey which global indices have enough funds, then choose and compare | Avoids mixing incomparable index universes by accident | MSCI only; MSCI plus FTSE |
| D-004 | 2026-11-05 | Project split into six gated phases (see PHASES.md). Source PDFs not committed to the public repo by default. | Each phase ends in a review; avoids redistribution issues | Single long build |
| D-005 | 2026-11-05 | Raw collected issuer data stays local. Repo publishes method, analysis, charts and write-up only. | Issuer terms allow personal use but restrict copying and publishing; none clearly allow republishing figures | Email issuers first; publish figures with attribution |
| D-006 | 2026-11-05 | Exclude SPDR's UK site as a source | It requires confirming you are a financial professional, which isn't true | Accepting the gate anyway |
| D-007 | 2026-11-05 | Never read content behind a terms acceptance box without accepting it first | Reading behind the box would sidestep the terms | Scraping the page underneath |
| D-008 | 2026-11-05 | Index scope (closes D-003): compare funds on MSCI World, MSCI ACWI and FTSE All-World | These three have several competing funds each (7, 3 and 4 core funds). FTSE Developed, FTSE Global All Cap and MSCI World IMI have one fund each, so no peer comparison; kept as context for the product view | MSCI World only (7 funds, too narrow for a gap view); all six families (single-fund groups can't be compared) |
| D-009 | 2026-11-05 | Inclusion rule: UCITS ETF, tracks one of the three indices above with no screen, factor, sector, size or regional tilt, not a currency-hedged-only fund, listed on the issuer's UK individual-investor site | Keeps like-for-like comparison | Including ESG and factor versions (different product, different fee logic) |
| D-010 | 2026-11-05 | One share class per fund: USD, unhedged, accumulating; if none, distributing | Share classes of the same fund can have very different fees, so the rule must be fixed in advance, not picked to suit a result | Cheapest class (biased); largest class (not always visible) |
| D-011 | 2026-11-05 | Tracking difference source: calendar-year fund vs index returns on issuer product pages. Defined as fund return minus index return, calculated by us the same way for every fund | Issuer pages show these tables. One issuer's own 'difference' column is not simple subtraction, so we don't use issuers' difference figures | Index provider data (licence terms unclear); dropping tracking difference |
| D-012 | 2026-11-05 | Xtrackers figures used for analysis but flagged before any public use | Xtrackers terms are the strictest found: any copying or use of site content needs written consent | Dropping Xtrackers (loses a major issuer from the comparison) |
| D-013 | 2026-11-06 | Source PDFs kept in data/docs on this machine only. Where a site won't serve a file to a script (Invesco) or has no plain link (Xtrackers), the file is saved from the browser instead | Keeps documents for checking without republishing them; doesn't try to get around a site that blocks scripted downloads | Working from the web pages only (no fixed copy to check against later) |
| D-014 | 2026-11-06 | Vanguard FTSE All-World: no factsheet on the UK investor site, so the product page figures (fee, assets, launch date) stand in for it in Phase 4 | The KIID is there; the page carries the same headline figures a factsheet would | Looking for a factsheet on Vanguard sites aimed at other investor types (not checked) |
| D-015 | 2026-11-06 | Fund size comes from factsheets only. Key documents don't report it, so a blank fund size from a key document counts as correct, not a miss | Avoids scoring the tool down for leaving out something that isn't there | Pulling fund size from product pages for every fund (mixes in a third source) |
